# Security

Treat input captures as untrusted and output reports as potentially private.
The tool reads local captures and writes new reports; it does not capture traffic,
change network settings, run commands from captures or send data to a server.

For parser crashes, resource-exhaustion bugs or report injection, provide only
a minimal synthetic reproducer. Do not post a real capture or private report.
For sensitive vulnerabilities, contact the repository owner through a private
GitHub vulnerability report when enabled; otherwise request a private contact
without disclosing exploit details in a public issue.

This version is not a security boundary or a validated malware detector.
